# Inventory and Purchase Order Analysis

## Project Overview

This project is about understanding how inventory is managed across five warehouses and analysing how purchase orders are fulfilled.

The main goal is to examine stock levels, track incoming orders, and identify supplier delivery delays. The analysis helps highlight inventory-related issues and provides useful insights for better decision-making.

## Tools Used

- **Power Query Editor:** Used for cleaning and transforming data.
- **MySQL:** Used to store and analyse structured data.
- **MySQL Workbench:** Used to create tables, manage the database, and execute SQL queries.
- **Power BI:** Used for data visualization and presenting insights through a dashboard.

## Project Workflow

1. Reviewed the inventory and purchase-order datasets.
2. Cleaned and transformed the data using Power Query Editor.
3. Imported the prepared data into MySQL Workbench.
4. Created database tables and worked with SQL queries.
5. Analysed inventory levels, order fulfillment, and delivery delays.
6. Used Power BI to present the analysis visually.

## What I Analysed

- Inventory levels across five warehouses.
- Stock quantities and inventory value.
- Purchase-order fulfillment status.
- Supplier delivery performance.
- Missing or incomplete received quantities.
- Delays in purchase-order deliveries.

## Key Findings

- Examined purchase-order fulfillment and identified fully received and partially received orders.
- Found records with missing received quantities.
- Analysed delivery delays to understand supplier performance.
- Reviewed inventory levels to understand stock availability across warehouses.

## Project Outcome

This project helped me gain practical experience in data cleaning, data transformation, SQL, and business analysis. It also helped me understand how inventory and purchase-order data can be used to identify operational issues and support business decisions.
